# SAIX SMC 指標規格

依據：與使用者逐題確認 + 笨錢社群 SMC 線下講義（第 11、14、15、18、38～56、132～137 頁）。

## 已確認規格

### 基本
- TradingView 指標，只看當前週期（不做高週期）
- 所有框都不畫中線
- 不做進出場訊號、不做警報（之後再說）

### ① 結構 BOS / MSS
| 項目 | 規則 |
|---|---|
| 高低點確認 | 預設「收盤跌破創高 K 棒的最低價」確認高點（低點反過來）；可切換「連續 N 根沒創新高」、「回落 X 倍 ATR」 |
| BOS | 收盤突破前一個高點（低點） |
| MSS | 收盤跌破「造成最近一次 BOS 的回撤低點」（空頭反過來）。CHoCH 改名為 MSS |
| 畫法 | 從高低點畫線到突破的那根 K 棒，標 BOS / MSS；不畫莊家成本區 |

### ② OB 訂單塊（9/25 修改）
- 只有造成 BOS / MSS 的那段走勢才畫 OB（不再看 FVG、不看實體大小）
- 空方 OB：下跌開始前的最後一根綠 K；多方 OB：上漲開始前的最後一根紅 K
- 空方框：開盤價 → 最高價；多方框：開盤價 → 最低價
- 碰到不算，一直往右延伸
- 收盤穿過整個 OB → 框停在那根、換灰色、標「破壞塊」
- 不畫中線；最多保留最近 10 個

### ③ FVG
- 不過濾，全部顯示
- 第一次被碰到就停止延伸，框保留
- 最多保留最近 10 個

### ④ 盤整 + PO3
| 項目 | 規則 |
|---|---|
| 盤整框 | 至少 2 個等高 + 2 個等低轉折點（誤差 0.3 倍 ATR，轉折點用結構規則）；上緣取最高、下緣取最低；收盤突破就停 |
| 操縱框 | 盤整後，至少一根 K 棒收盤在區間外 |
| 擴張確認線 | 從 A（操縱前最後一個轉折點）畫到收盤突破 A 的那根 K 棒 |
| 擴張 | 在確認的那根 K 棒上方 / 下方寫「擴張」 |

### ⑤ 流動性
- 只畫盤整框上緣 / 下緣的虛線，往右延伸，收盤穿過才停

### ⑥ 溢價 / 折價區
- 範圍：最近一個確認的高點 ↔ 最近一個確認的低點（每確認一個新高 / 低點就更新）
- 上半淡紅＝溢價、下半淡綠＝折價，只畫最新一段

### ⑦ 資訊面板
- 結構多空、在溢價或折價區、最近一次 BOS / MSS

## 簡單版中「我先自己決定、還沒跟使用者確認」的細節

之後要逐項確認：

1. **操縱框的範圍**：從第一根收盤出區間的 K 棒，畫到收盤回到區間內的那根；框的一邊是盤整邊緣，另一邊是這段期間的極值。**要等擴張確認後才畫出來**（沒確認擴張的突破不畫操縱框）
2. **PO3 取消條件**：出現新的盤整框時，舊的 PO3 觀察就取消
3. **盤整判定**：用「最近連續 4 個轉折點」（2 高 2 低）判斷
4. **MSS 之後的新守點**：MSS 反轉後，新的守點＝被突破的守點到 MSS 那根之間的最低點（空頭反過來）
5. **沒有趨勢時的第一次突破**：標成 BOS
6. **逆勢的小高低點被突破**：直接忽略，不畫（例如空頭中突破一個比 MSS 位置低的小高點）
7. **FVG 被碰到**：多方是最低價 ≤ 框上緣，空方是最高價 ≥ 框下緣
10. **OB 的「起漲 / 起跌點」**：用這段走勢的最低點（最高點）那根往回找，含它自己，找最近一根反方向 K 棒（最多往回 50 根）
8. **HH / HL / LH / LL 小字**：舊版有，新版先拿掉（使用者還沒回答）
9. 顏色、文字標籤、面板位置
