# 賽克斯 SMC 看盤輔助指標

TradingView 用的 Pine Script v5 指標，檔案：`saix_smc.pine`

## 安裝

1. TradingView 下方打開「Pine 編輯器」
2. 把 `saix_smc.pine` 全部內容貼上，覆蓋原本的程式碼
3. 按「加到圖表」

## 圖上會看到什麼

| 功能 | 圖上長相 | 怎麼看 |
|---|---|---|
| **BOS**（結構延續） | 實線＋「BOS」 | 順勢突破前一個波段高／低，趨勢延續 |
| **CHoCH**（結構轉換） | 虛線＋「CHoCH」 | 逆勢突破，趨勢可能反轉，是最早的轉向警訊 |
| **HH / HL / LH / LL** | 灰色小字 | 波段高低點，HH＋HL＝多頭，LH＋LL＝空頭 |
| **訂單塊 OB** | 綠／紅色方塊，往右延伸 | 突破前最後一段走勢的極端 K 棒，價格回來常有反應；收盤穿越就刪除 |
| **FVG**（公允價值缺口） | 藍／橘色小方塊 | 三根 K 棒中間留下的缺口，被回補會縮小，補滿就消失 |
| **EQH / EQL** | 點狀線 | 等高／等低，上下方聚集停損（流動性），容易被掃 |
| **溢價／折價區** | 上半淡紅、下半淡綠、中間 EQ 50% 虛線 | 在折價區找多、溢價區找空 |
| **資訊面板** | 右上角表格 | 本週期／高週期趨勢、是否共振、價格位置、最近結構 |

## 進場訊號（OB 回踩）

條件（K 棒**收盤確認**後才出現，不會重繪）：

- 做多：本週期結構為多頭 → 價格回踩還沒用過的多方 OB → 收盤仍在 OB 下緣之上
- 做空：反過來
- 可選過濾：「做多須在折價區」（預設開）、「須與高週期同向」（預設關）
- 停損＝OB 外側再加一點 ATR 緩衝；圖上止盈預設 1R（可調）

每個 OB 只會觸發一次訊號。

## 警報

建立警報時「條件」選 **SAIX SMC**，可以選：

- 多方／空方 CHoCH、多方／空方 BOS
- 做多／做空訊號（OB 回踩）

觸發頻率建議選「**K 棒收盤時**」。

## 串接自動交易（server.py）

⚠️ **這會真的在 OKX 下單，預設是關閉的。**

1. 指標設定 → ⑦ 進場訊號 → 勾選「送出自動交易 JSON」
2. 建立警報，條件選 **SAIX SMC** →「任何 alert() 函數呼叫」
3. Webhook URL 填 `https://<你的 Railway 網址>/webhook?secret=<WEBHOOK_SECRET>`
4. 訊息欄位不用填，指標會自己送出：

```json
{"symbol":"BTCUSDT","side":"buy","entry":63000.1,"sl":62500.0,"sl_pct":0.7937,"trend_aligned":true}
```

- `symbol` 會自動去掉永續合約的 `.P`（`BTCUSDT.P` → `BTCUSDT`）
- `trend_aligned` 表示訊號方向是否跟高週期趨勢一致
- server.py 用 1:1 算止盈，圖上的 R 倍數設定不影響下單

建議先用小資金或只看訊號跑一段時間，確認勝率再開自動下單。

## 參數建議

| 圖表週期 | 波段長度 | 高週期 |
|---|---|---|
| 5m / 15m | 10 | 1H |
| 1H | 10 | 4H |
| 4H | 10 | 1D |

波段長度越大 → 結構越大、訊號越少但比較穩；越小 → 訊號多、雜訊也多。
