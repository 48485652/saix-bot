# 賽克斯 SMC 看盤輔助指標（簡單版）

TradingView 用的 Pine Script v5 指標，檔案：`saix_smc.pine`
完整規格與待確認事項：`SPEC.md`

## 安裝

1. 在 GitHub 打開 `saix_smc.pine`，點右上角「Copy raw file」一次複製整份
2. TradingView 下方打開「Pine 編輯器」，**⌘A 全選 → ⌘V 貼上**，把原本內容整個蓋掉
3. 確認第 1 行是 `//@version=5`、右下角顯示 **Pine Script® v5**
4. 按「新增到圖表」

## 圖上會看到什麼

| 功能 | 圖上長相 |
|---|---|
| **BOS** | 實線＋「BOS」，收盤突破前高 / 前低 |
| **MSS** | 虛線＋「MSS」，收盤突破造成最近一次 BOS 的回撤點 |
| **OB** | 綠 / 紅框，造成 BOS / MSS 的走勢起漲（起跌）前最後一根反方向 K 棒；收盤穿過變灰色「破壞塊」 |
| **FVG** | 藍 / 橘框；被碰到就停止延伸 |
| **盤整** | 藍框，2 個等高 + 2 個等低；收盤突破就停 |
| **流動性** | 盤整上下緣的灰色虛線，收盤穿過才停 |
| **操縱** | 紫框，盤整後收盤跑出區間的那一段（確認擴張後才畫） |
| **擴張** | 黃線（操縱前最後一個轉折點 → 突破它的 K 棒）＋「擴張」字樣 |
| **溢價 / 折價** | 最近一段高低點，上半淡紅、下半淡綠 |
| **資訊面板** | 右上角：結構多空、價格位置、最近結構 |

## 常用設定

- **高低點確認方式**：預設「收盤跌破創高K棒」，可切換另外兩種比對看看哪個最接近你的畫法
- **等高 / 等低誤差**：盤整框太少就調大，太多就調小（預設 0.3 倍 ATR）
- OB、FVG 最多各保留 10 個，可調
